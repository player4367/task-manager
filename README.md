# Название программы 
Менеджер задач

## Описание программы
Эта программа предназначена для удобного контроля повседневных задач, своего рода список задач, которые вам нужно сделать.

## Возможности программы
- Добавлять задачи в список
- Удалять из него ненужные или выполненные задачи
- Отмечать выполненные и невыполненные задачи
- Выводить список на экран для удобства

## Установка и запуск

1. Чтобы запустить программу, нужно, чтобы Python был установлен на компьютере
2. Скачать файл task_manager.py себе на компьютер
3. В терминале открытом в папке с файлом task_manager.py написать python task_manager.py и нажать Enter.
